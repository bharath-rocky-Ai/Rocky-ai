ROCKY AI – installable PWA starter

This package is a Progressive Web App (PWA). To get an Install app / Add to Home screen option:
1. Upload the contents of this folder to a static web host that serves HTTPS.
2. Open the resulting HTTPS URL in Chrome on Android.
3. Tap Chrome ⋮ and choose "Install app" or "Add to Home screen".

Important:
- This is still a prototype. Chat replies are demo replies, not real AI.
- PIN/reminders are stored locally in the browser on that device.
- Hosting it at an unlisted URL does not make it truly private; anyone with the URL may open it.
- Do not put API keys in these files. A real AI connection needs a secure server/backend.
